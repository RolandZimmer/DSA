TÌM KIẾM TUYẾN TÍNH

Khi nào nên dùng?

Nên dùng khi

  • Danh sách có kích thước nhỏ.
  • Dữ liệu chưa được sắp xếp.
  • Cấu trúc không hỗ trợ truy cập ngẫu nhiên, như danh sách liên kết đơn.
  • Chi phí sắp xếp lớn hơn lợi ích tìm kiếm.

Không nên dùng khi

  • Tập dữ liệu rất lớn.
  • Dữ liệu đã được sắp xếp.
  • Cần tìm nhiều lần trên cùng một tập dữ liệu.

TÌM KIẾM TUYẾN TÍNH

Từ mã giả đến C++

MÃ GIẢ

PROCEDURE Linear_Search(Array, Target_Value)
  FOR i = 0 TO length(Array) - 1
    IF Array[i] = Target_Value THEN
      RETURN i
    END IF
  END FOR
  RETURN -1
END PROCEDURE

C++

int linearSearch(int arr[], int n, int x) {
  for (int i = 0; i < n; i++) {
    if (arr[i] == x)
      return i;
  }
  return -1;
}

TÌM KIẾM NHỊ PHÂN

Điều kiện bắt buộc: dữ liệu đã sắp xếp

Phù hợp nhất

  • Tập dữ liệu lớn và đã sắp xếp.
  • Dữ liệu tĩnh hoặc ít thay đổi.
  • Mảng hoặc vector có truy cập ngẫu nhiên O(1).
  • Truy vấn biên: đầu, cuối, vị trí chèn, giá trị gần nhất.

Không phù hợp

  • Dữ liệu chưa sắp xếp hoặc thay đổi thường xuyên.
  • Danh sách liên kết không truy cập nhanh được phần tử giữa.
  • Tập dữ liệu quá nhỏ.
  • Cần tìm mọi phần tử trùng nhưng không dùng biến thể tìm biên.

TÌM KIẾM NHỊ PHÂN

Cài đặt C++ dạng lặp

int binarySearch(int array[], int n, int target) {
  int left = 0;
  int right = n - 1;
  while (left <= right) {
    int mid = left + (right - left) / 2;
    if (array[mid] == target) return mid;
    if (array[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
mid = left + (right - left) / 2tránh tràn số so với (left + right) / 2

03 — TÌM KIẾM NỘI SUY

Ước lượng trước.
Thu hẹp sau.

Thay vì luôn kiểm tra điểm giữa, tìm kiếm nội suy dự đoán vị trí dựa trên giá trị cần tìm so với hai đầu của miền tìm kiếm.

Giống như mở danh bạ gần chữ “Y” thay vì mở đúng giữa cuốn sách.

pos = low +
(x − a[low]) × (high − low)a[high] − a[low]

TÌM KIẾM NỘI SUY

Nhanh — chỉ khi dữ liệu phù hợp

Nên dùng khi

  • Mảng đã được sắp xếp.
  • Các giá trị phân bố gần đồng đều.
  • Tập dữ liệu lớn và được tìm kiếm nhiều lần.
  • Có khả năng truy cập ngẫu nhiên.
Trung bìnhO(log log n)

Không nên dùng khi

  • Các giá trị bị lệch hoặc tập trung thành cụm.
  • Mảng chưa được sắp xếp.
  • Tập dữ liệu nhỏ.
Xấu nhấtO(n)

TÌM KIẾM NỘI SUY

Cài đặt C++

int interpolationSearch(int arr[], int n, int x) {
  int low = 0, high = n - 1;
  while (low <= high && x >= arr[low] && x <= arr[high]) {
    if (arr[high] == arr[low])
      return arr[low] == x ? low : -1;
    int pos = low + (double)(x - arr[low]) *
              (high - low) / (arr[high] - arr[low]);
    if (arr[pos] == x) return pos;
    if (arr[pos] < x) low = pos + 1;
    else high = pos - 1;
  }
  return -1;
}
